# Rep One Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Every UI task (5, 6, 8) also uses impeccable: read its `reference/craft-floor.md` before the first UI edit.

**Goal:** A three-page web app (landing → catalogue → exercise detail) that teaches the Seated Cable Row step by step with an animated 3D placeholder mannequin, built for a live HackOhio demo in Chromium.

**Architecture:** A Vite multi-page app in plain TypeScript. Pure logic (`src/lib`) and data (`src/data`) are unit-tested with Vitest. Pages are thin DOM modules. Three.js lives only in `src/viewer`, which the exercise page loads with a dynamic `import()`. Page transitions use native cross-document View Transitions.

**Tech Stack:** Vite 5, TypeScript 5 (strict), Three.js (r16x, `three/examples/jsm` for OrbitControls + GLTFLoader), Vitest, `@fontsource-variable/archivo` (self-hosted font, justified below).

**Spec:** `docs/superpowers/specs/2026-10-24-rep-one-design.md`. **Product:** `PRODUCT.md`. **Direction contract:** `.impeccable/surfaces/index-html.md`. Executors read all three.

## Global Constraints

- Runtime dependencies: `three` and `@fontsource-variable/archivo` only. The font is a CSS-only package, self-hosted so the demo never depends on network fonts. No other runtime dependency.
- Development dependencies: `vite`, `typescript`, `vitest`, `@types/three`. All tests are pure logic and data and run in Node; UI is verified in the browser.
- Target browser: Chromium on Windows. Firefox and Safari must not break; they get the solid fallbacks.
- Copy: plain-language, encouraging, no jargon; any term is defined inline the first time it appears. No invented claims (testimonials, user counts, endorsements).
- Every missing media file (GIF, video, poster, GLB) shows a labelled placeholder, never a broken image.
- `prefers-reduced-motion: reduce` disables parallax, tweens (values apply instantly), view transition animation and video autoplay.
- `prefers-reduced-transparency: reduce` or no `backdrop-filter` support: glass buttons render solid.
- WCAG 2.2 AA: text contrast ≥ 4.5:1 (≥ 3:1 for large text and UI boundaries), full keyboard operation, visible focus.
- JS budget, gzipped: landing ≤ 30 KB, catalogue ≤ 30 KB, exercise page ≤ 30 KB, viewer chunk ≤ 200 KB. Enforced by `npm run build`.
- The direction contract text is never copied into source, comments or the DOM.
- The Seated Cable Row content carries the line "Draft — to be reviewed by a qualified coach before public release." in its data file header and on the detail page.

## Review Focus

1. **Deep link with a bad or missing `?id`.** `exercise.html`, `exercise.html?id=`, `?id=../x`: expect the "We couldn't find that exercise" view, not a crash. Test in Task 3 (`resolveExercise`).
2. **Hand-edited catalogue URL** (`?muscle=back,nope&sort=zzz&difficulty=`): expect unknown values dropped, the default sort, and no exception. Test in Task 3.
3. **Rapid step clicking while a tween runs.** Expect smooth retargeting from the current values, no snap, and the final pose equal to the last-clicked step. Test in Task 4 (`Tween.retarget`), with a behaviour check in Task 9.
4. **Scrubbing exactly to 0 or 1, or past the last key, on the rep track.** Expect the first or last pose, never undefined joints. Test in Task 4 (`samplePose` endpoints).
5. **Missing `public/models/human.glb`, the default today.** Expect the mannequin, the placeholder badge, and no console error beyond the handled 404. Checked in Tasks 7 and 9.

## Design System (impeccable, settled)

The world is **an assembly manual for your body, printed on one ultramarine flood**. Every page is drenched in a single blue; white line art and type sit on it; depth comes only from overlapping flat tints of that blue, never shading or gradients. Steps are giant numerals. Mistakes are drawn as ✕ frames and good form as ✓.

### Colour (Drenched strategy, one hue, 264°)

Define these in `src/styles/tokens.css`:

| Token | Value | Use |
|---|---|---|
| `--flood` | `oklch(0.47 0.24 264)` | page background, every page |
| `--flood-deep` | `oklch(0.36 0.20 264)` | 3D viewport field, filter bar, footer band |
| `--flood-mid` | `oklch(0.56 0.21 264)` | parallax mid layer, card hover ring, floor grid |
| `--flood-light` | `oklch(0.70 0.14 264)` | parallax far layer, outline numerals, muted line art |
| `--paper` | `#ffffff` | type and line art on flood, card and panel surfaces |
| `--ink` | `oklch(0.28 0.16 264)` | text on paper (cards, ✕ panel, active chips) |
| `--ink-soft` | `oklch(0.42 0.12 264)` | secondary text on paper (contrast ≥ 4.5:1 with white) |
| `--paper-soft` | `oklch(0.90 0.05 264)` | secondary text on flood (contrast ≥ 4.5:1 with `--flood`) |

There are no other hues: no red for errors and no green for success. Error and warning states use the ✕ frame on paper. The only gradient anywhere is the glass specular highlight.

### Typography

One family: **Archivo** variable (`wght` 100–900, `wdth` 62–125), imported from `@fontsource-variable/archivo/wdth.css`.

| Role | Size | wdth / wght | Other |
|---|---|---|---|
| Display (step numerals, "See catalogue", wordmark at hero scale) | `clamp(64px, 10vw, 168px)` | 125 / 900 | line-height 0.86, tracking −0.02em |
| H1 (page titles, exercise name) | `clamp(40px, 5.2vw, 76px)` | 112 / 800 | line-height 0.95 |
| H2 (step title, section heads) | `clamp(24px, 2.4vw, 32px)` | 100 / 750 | line-height 1.1 |
| Body | 18px (17px under 480px) | 100 / 420 | line-height 1.55, max 62ch |
| Label ("Fig. 1", "No. 01", chip text, captions) | 13px | 88 / 700 | uppercase, tracking 0.08em |

The scale jumps straight from Display to Label with no in-between "subtitle" size. Large numerals are always next to a small label, for example a `05` numeral with "STEP 5 OF 7".

### Spacing, shape, line

- Spacing tokens: `--s1:4px --s2:8px --s3:12px --s4:16px --s5:24px --s6:32px --s7:48px --s8:64px --s9:96px`. Section gaps are `--s9`; there is always more space above a heading than below it.
- Radius: panels `32px`, cards `20px`, chips and buttons `999px`.
- Line: 2px white "manual rule" lines for frames and dividers, and a 1.5px stroke for line art. No box shadows except the glass rim.
- Layout: a 12-column grid with `--s5` gutters and `max-width: 1440px`, centred, with side padding `clamp(16px, 4vw, 56px)`.

### Liquid glass button (`src/styles/glass.css`, class `.glass`)

- Base, which is also the fallback: `--paper` fill, `--ink` label, 999px radius, padding 18px 30px, Label type at 15px, and a `→` glyph after the label.
- Enhanced: applied when `.glass-refract` is on `<html>`, set by `src/lib/glass.ts` under three conditions: `CSS.supports('backdrop-filter','blur(1px)')`, the browser is Chromium (`navigator.userAgentData?.brands` contains "Chromium"), and reduced transparency is not requested.
  - Translucent white tint `rgb(255 255 255 / 0.18)` with `backdrop-filter: url(#glass-distort) blur(6px) saturate(1.6)`.
  - A 1px inner rim `rgb(255 255 255 / 0.55)` and a top specular sheen (a linear-gradient white 0.45 → 0 over the top 50%).
  - Paper label at weight 800.
  - The label sits on its own `--flood-deep` 0.35 tint pill so contrast is ≥ 4.5:1 regardless of what's refracted.
- `#glass-distort` is an inline SVG filter included once per page: `feTurbulence` (baseFrequency 0.008, numOctaves 2) into `feDisplacementMap` (scale 28).
- Hover: the specular sheen shifts 12px and the button scales 1.02 over 220ms. Active: scale 0.98. Focus: the global focus ring.
- The same `.glass` class is used for every primary action: "Browse exercises", the detail page's "Next step", "Back to catalogue", and the empty state's "Clear filters".

### Focus

Global `:focus-visible` is `outline: 3px solid var(--paper); outline-offset: 3px; box-shadow: 0 0 0 6px var(--ink)`, a double ring that reads on both the flood and paper.

### Page transitions (`src/styles/transitions.css`)

- `@view-transition { navigation: auto; }`.
- Root: the old page fades and moves up 16px over 220ms; the new page fades in over 280ms with `cubic-bezier(.2,.8,.2,1)`.
- Card to detail: the clicked card's preview window gets `view-transition-name: exercise-hero` on `pageswap`/click, and the detail viewport (or the Coming soon frame) has `view-transition-name: exercise-hero`. Morph over 450ms with the same easing.
- Back navigation: `pagereveal` on the catalogue sets the name on the card whose id matches `sessionStorage['rep-one:last-id']`, which is wrapped in try/catch.
- Reduced motion: `::view-transition-group(*), ::view-transition-old(*), ::view-transition-new(*) { animation: none; }`.
